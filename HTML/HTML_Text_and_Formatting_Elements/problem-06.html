My Programming Notes

JavaScript

JavaScript is mainly used for web development to make pages interactive. It runs directly in the browser and powers dynamic websites. 


    // JavaScript Example
    let message = "Hello World!";
    console.log(message);

Java

Java is widely used for enterprise applications, Android apps, and large systems. It is platform-independent thanks to the JVM. 


    // Java Example
    public class HelloWorld {
        public static void main(String[] args) {
            System.out.println("Hello World!");
        }
    }

Python

Python is popular for data science, AI, and scripting. It emphasizes readability and simplicity. 


    # Python Example
    message = "Hello World!"
    print(message)
